# Legitimate low-risk change is obstructed

**Source:** mcp

The agent refuses, hedges, or demands unnecessary steps for a legitimate in-scope request — most visibly a clean low-risk dev change that policy allows to proceed directly. Engineers route around the agent to the manual path, losing both its speed and whatever enforcement it carried. An assistant that obstructs legitimate work is removed, and its protection leaves with it.</description>
<parameter name="additional_context">[for: failure-analysis] The system prompt already contains an explicit instruction not to refuse legitimate in-scope requests and names clean low-risk dev changes specifically, which indicates over-refusal is an observed tendency rather than a hypothetical. Adding enforcement can only increase this pressure, so it must be measured alongside violation reduction.
